Description — editorial target: 80–120 words, excluding URLs:

```text
Homestead brings hyperconvergence home: compute, storage and networking across ordinary machines, with a friendly interface for apps, volumes and VMs. Built on Kubernetes and source-available, it simplifies cluster setup, node management and upgrades alongside replicated Longhorn storage, KubeVirt VMs, backups, shares and virtual IPs.

It is aimed at homelab owners moving from a single server to several machines. A guided installer can set up k3s or RKE2; existing Kubernetes and Harvester clusters are also supported. The project is currently beta, and resilience depends on the cluster's configuration and available hardware.

Interactive demo with sample data: https://wjcloudy.github.io/homestead/
Documentation: https://github.com/wjcloudy/homestead/wiki
```
