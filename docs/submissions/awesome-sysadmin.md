## Eligibility gaps

The list requires a first release more than **12 months** old, software intended for professional use, and a healthy contributor ecosystem for a submission of one's own project. The PR template also asks for first-hand usage duration, deployment context, scale and balanced comparisons. Homestead's repository was created on 19 September 2026, currently describes itself as beta and targets homelabs. Evidence meeting those requirements has not been established.

There is no automatic “submit next September” date: establish the original public release date, professional-use fit and contributor evidence first. Do not check the eligibility boxes or invent usage history. The guide warns against AI-generated contributions that violate its rules.

## Evidence to collect before an actual PR

| Upstream question / check | Required human evidence |
|---|---|
| Why is it awesome? | Your assessment of how cluster setup, upgrades and combined app, VM, storage and network workflows helped in real use |
| Have you used it? For how long? | Actual dates and duration |
| Personal or professional setup? | Actual deployment context; explain professional relevance without relabelling a home lab |
| How many devices/users/services? | Actual counts |
| Biggest pros/cons? | A balanced comparison based on tools you have used, including beta maturity and cluster complexity |
| Other comments? | Observed limitations, useful workflows and operational experience |
| First release >12 months ago | Dated public release evidence |
| Own-project submission | Real contributor/ecosystem evidence and affiliation disclosure |
| No duplicate | Search open and closed upstream issues/PRs and the other lists specified in the current template |

When eligible, use the exact then-current PR template and keep its checklist intact. This pack does not supply checked attestations or a fabricated testimonial.
