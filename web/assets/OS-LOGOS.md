# Operating system logos

The marks in `os-*.svg` come from [Simple Icons](https://simpleicons.org) 16.34.0, drawn on each brand's colour.
Simple Icons is CC0; some marks carry their own licence, listed below. Each logo is a trademark of its owner
and is used here only to show which operating system a VM runs. `os-windows.svg` is Homestead's own
neutral window glyph, not Microsoft's logo.
